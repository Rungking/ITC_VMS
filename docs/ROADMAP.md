> ระยะเวลาประเมินสำหรับทีมเต็ม ช่วงแรก backend มีผู้ทำคนเดียว Phase 0–1 อาจยืดออก

จุดเริ่มต้นเร็วกว่าเขียนใหม่ เพราะได้ของที่ทำแล้วมา 2 ทาง:
- **จาก CCTV:** ไดรเวอร์ Dahua + NetSDK, ภาพสด NVR → MediaMTX → WebRTC (ทดสอบกับเครื่องจริงแล้ว), login/RBAC/audit log
- **จากต้นแบบ:** หน้าตาเว็บ, แผนที่, Topology, Dashboard, ฟอร์มกล้อง, ภาษาไทย/อังกฤษ

**นอกขอบเขต:** กล้อง Bodyworn (Pe IMS) แยกเป็นโครงการต่างหากร่วมกับ partner

---

## Phase 0: รวมโค้ดและถอด ZoneMinder (2–3 สัปดาห์)

**เป้าหมาย:** repo เดียว รันทั้งระบบได้ด้วยคำสั่งเดียว หน้าเว็บของต้นแบบแสดงข้อมูลจาก backend ใหม่ ไม่มี ZoneMinder
**งาน:** B-01 ถึง B-08 · W-01 ถึง W-07

**เสร็จเมื่อ:** `docker compose up` แล้วเข้าหน้าเว็บของต้นแบบ, login ด้วยบัญชีจริงได้, หน้าตั้งค่ากล้องเพิ่ม/แก้/ลบผ่าน backend ใหม่ได้

---

## Phase 1: อุปกรณ์ ภาพสด แผนที่ Topology (6–7 สัปดาห์)

**เป้าหมาย:** ผู้ดูแลเพิ่ม NVR ได้เอง และผู้ใช้ดูภาพสดหลายจอได้ลื่นกว่าต้นแบบเดิมอย่างเห็นได้ชัด
**งาน:** B-10 ถึง B-16 · W-10 ถึง W-15

**เสร็จเมื่อ:** เพิ่ม NVR ในแล็บแล้วเห็นกล้องทุกตัวบนแผนที่และ Topology, ดู 16 จอพร้อมกันได้ลื่น, เซิร์ฟเวอร์ใช้ CPU ต่ำกว่าตอนใช้ ZoneMinder (วัดเทียบ)

---

## Phase 2: บันทึกและย้อนหลัง (6 สัปดาห์)

**เป้าหมาย:** บันทึกบนเซิร์ฟเวอร์ตามค่าเริ่มต้น **15 วัน 1080p** (ปรับได้ทั้งระบบและรายกล้อง) และดูย้อนหลังได้ทั้งจากเซิร์ฟเวอร์และ NVR
**งาน:** B-20 ถึง B-23 · W-20, W-21

**เสร็จเมื่อ:** ย้อนดูเหตุการณ์เมื่อวานได้ทั้งจากเซิร์ฟเวอร์และ NVR, ส่งออกคลิปได้ใน 3 คลิก, ไฟล์เก่ากว่าค่าที่ตั้งถูกลบอัตโนมัติ

---

## Phase 3: แจ้งเตือน (4–5 สัปดาห์)

**งาน:** B-30 ถึง B-32 · W-30, W-31

**เสร็จเมื่อ:** เดินผ่านกล้อง AI แล้วหน้าจอแจ้งเตือนภายใน 2 วินาที พร้อมภาพ

---

## Phase 4: ทดสอบระบบใหญ่และนำร่อง (4 สัปดาห์) ⭐ จุดส่งมอบแรก

**งาน:** B-40 ถึง B-42 · W-40, W-41 · ติดตั้งนำร่อง 1 แห่ง

**เสร็จเมื่อ:** ทำงานต่อเนื่อง 2 สัปดาห์โดยไม่ต้องแก้ฉุกเฉิน

---

## Phase 5: ขยายต่อ (ต่อเนื่อง)

- ONVIF, Hikvision, Uniview
- ไดรเวอร์ตั้งค่า main stream ของกล้องเป็น 1080p ให้อัตโนมัติ
- PTZ, Video Wall + Tour, แจ้งเตือนทาง LINE/Telegram/Email
- ระบบ License (ต่อจาก `LicenseProvider` ของต้นแบบ), หลายสาขาในระบบเดียว, 2FA

---

## ความเสี่ยงหลัก

| ความเสี่ยง | วิธีรับมือ |
|---|---|
| Backend มีผู้ทำคนเดียว | ทำตามลำดับใน [tasks/README.md](tasks/README.md), API มีเอกสาร OpenAPI ให้ฝั่ง web ใช้ได้เลย |
| พื้นที่ดิสก์ที่ค่าเริ่มต้น 1080p 15 วัน สูง (~650 GB ต่อกล้องถ้าเป็น H.264) | ใช้ H.265 ใน main stream, หน้าตั้งค่าแสดงประมาณการดิสก์, ปรับรายกล้องเป็นภาพประหยัดหรือเฉพาะเหตุการณ์ |
| หน้าจอต้นแบบผูกกับรูปแบบข้อมูลของ ZoneMinder (`zmId`, `function`, `colours` ฯลฯ) | กำหนด type `Camera` ใหม่ฝั่ง web (W-04) ก่อนแก้หน้า, แก้ทีละหน้า |
| ยังไม่เคยรัน `docker compose` บน Linux | B-07 ใน Phase 0 |
| เงื่อนไข license เชิงพาณิชย์ของ Dahua NetSDK | สอบถาม Dahua ก่อนขายจริง |
| เบราว์เซอร์เล่น H.265 ไม่ได้ | บังคับ sub-stream เป็น H.264 (ภาพสดในจอย่อย) |
