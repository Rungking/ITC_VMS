# ระบบติดตามงาน (2 สาย)

งานแบ่งเป็น 2 สายตามเครื่องมือที่ใช้ เพื่อให้สลับไปทำสายไหนก็ได้ แล้วรู้ทันทีว่าค้างอะไรอยู่

| สาย | ไฟล์ | เครื่องมือ | โฟลเดอร์ |
|---|---|---|---|
| **Backend** (B) | [BACKEND.md](BACKEND.md) | Python, FastAPI, NetSDK, MediaMTX, อุปกรณ์จริงในแล็บ | `backend/`, `deploy/` |
| **Web** (W) | [WEB.md](WEB.md) | Next.js, TypeScript, เบราว์เซอร์ | `web/` |

แผนรวมแต่ละ Phase และเกณฑ์ "เสร็จเมื่อ" อยู่ที่ [ROADMAP.md](../ROADMAP.md)

## กติกา

- งานแต่ละชิ้นมีรหัส เช่น `B-03`, `W-05` อ้างในชื่อ branch และ commit ได้ (`B-03: login sets httpOnly cookie`)
- สถานะ: `[ ]` ยังไม่เริ่ม · `[~]` กำลังทำ · `[x]` เสร็จ
- **ต้องการ:** งานที่ต้องเสร็จก่อน (ข้ามสายได้ เช่น W-05 ต้องรอ B-03)
- **ส่งต่อ:** งานในอีกสายที่รองานนี้อยู่ เมื่อทำเสร็จให้ไปดูว่างานนั้นเริ่มได้แล้วหรือยัง
- ก่อนสลับสาย ให้อัปเดตสถานะงานที่ค้าง และเขียนสั้นๆ ใต้หัวข้อ **ค้างไว้** ของสายนั้นว่าหยุดตรงไหน
- งานใหม่ที่เจอระหว่างทำ เพิ่มท้าย Phase ที่เกี่ยวข้องด้วยรหัสถัดไป ไม่ต้องเรียงใหม่
